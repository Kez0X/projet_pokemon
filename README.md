# Projet AD : qu'est-ce qui rend un Pokémon populaire ?

Projet en binôme (Luka, Lucas) du cours de DAD (M2). On applique les méthodes vues en cours et en TP (exploration, clustering, réseaux, transformations) à la popularité des Pokémon. Le rendu est un dashboard Dash.

## Pipeline

La pipeline complète (sources, collecte, analyses, dashboard et répartition des tâches) est dans [`docs/pipeline.excalidraw`](docs/pipeline.excalidraw). Pour l'ouvrir, glisser le fichier sur [excalidraw.com](https://excalidraw.com).
